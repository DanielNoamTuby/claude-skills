# Public Skills

General-purpose versions of the skills in this repository.

## Included skills

- `token-saver` — reduce context and tool-call waste without skipping necessary verification
- `work-report` — produce concise, evidence-based completion reports
- `grill-me` — stress-test a plan or design before documenting it
- `design-brief` — capture product and experience intent
- `design-flow` — guide a design-to-build workflow
- `information-architecture` — define navigation, structure, and user flows
- `design-tokens` — create or extend a visual token system
- `brief-to-tasks` — turn a design brief into ordered vertical slices
- `frontend-design` — build interfaces around an explicit visual direction
- `design-review` — critique a built interface against its intended design

The files in this folder are generalized exports. They do not require this
repository, its directory layout, its commands, its services, or its private
data.

See `NOTICE.md` for attribution and licensing information. The two
project-authored skills use MIT; the eight adapted design skills use
Apache-2.0.
